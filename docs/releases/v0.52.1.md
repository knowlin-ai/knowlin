# Knowlin 0.52.1 – Faster start, one website page per body

*Deutsch unten.*

- **Faster start on Windows:** Knowlin no longer waits for the Claude SDK while starting. On some PCs that took
  40–140 s because the virus scanner checks each of its many files; it now loads in the background.
- **knowlin.de: one page per body**, in English and German – Microduck, Reachy Mini, Open Duck Mini, SO-101,
  Stack-chan and Bittle X, each with its own address (e.g. `knowlin.de/en/microduck/`).
- **Not tested:** how much faster the start is on your PC – after the update, restart once; `duckpilot.log` shows
  “Start nach … s: bereit”.

## Deutsch

- **Schnellerer Start unter Windows:** Knowlin wartet beim Start nicht mehr auf das Claude-Paket. Auf manchen PCs
  dauerte das 40–140 s, weil der Virenschutz jede der vielen Dateien prüft; jetzt lädt es im Hintergrund.
- **knowlin.de: eine Seite je Körper**, deutsch und englisch – Microduck, Reachy Mini, Open Duck Mini, SO-101,
  Stack-chan und Bittle X, jeweils mit eigener Adresse (z. B. `knowlin.de/microduck/`).
- **Nicht geprüft:** wie viel schneller der Start bei dir ist – nach dem Update einmal neu starten; `duckpilot.log`
  zeigt „Start nach … s: bereit“.
