# Knowlin 0.38.49 – update check picks the highest version

*Deutsch unten.*

- **Fixed:** the update check and the website's download button now pick the highest version instead of the most
  recently created release. When an older release is published later, Knowlin no longer offers it as an update.

## Deutsch

- **Behoben:** Update-Suche und Download-Knopf der Website nehmen jetzt die höchste Version statt des zuletzt angelegten
  Releases. Wird eine ältere Version nachgereicht, bietet Knowlin sie nicht mehr als Update an.

Unten unter „Assets“: `Knowlin-Setup-0.38.49.exe`.
