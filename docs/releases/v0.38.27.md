# Knowlin 0.38.27 – Policies from Isaac Lab, Knowlin everywhere, tablet, memory with topics

*Deutsch unten.*

- **Policies from Isaac Lab:** Learn → Training imports the walking policy NVIDIA's Isaac Lab exports for the Microduck
  (`exported/policy.onnx`). Knowlin checks that it fits (61 observations, 14 joints in the same order, same default pose,
  50 Hz) and runs a test bench in the physics simulator – standing, forward, sideways, turning and a push, both as trained
  and with the real robot's smoothing, optionally measured against Pollen's gait. Only a policy that passes is cleared for
  the real duck; trying it in the physics simulator always works.
- **What Knowlin knows about your world:** topic cards above the network – people (PC only), places, things, activities –
  with how much Knowlin knows, how it feels (sign and word, never colour alone), when last experienced and how certain.
  Below the network, a plain-language legend.
- **Knowlin everywhere:** shortcuts are called “Knowlin” and “Knowlin - Microduck”; old ones are renamed once and kept
  pointing at the current version (never from a branch folder). The installable web app is called Knowlin.
- **Tablet:** touch targets at least 44 px; the acceptance test checks portrait (820 px) and landscape (1180 px).
- **Odi remembers bumps:** without any depth sensing it remembers where it got stuck, bumped or fell and walks around
  that spot next time.
