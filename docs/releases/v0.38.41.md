# Knowlin 0.38.41 – room on the phone, LM Studio as a local model

*Deutsch unten.*

- **Phone view with room to talk:** the cockpit fits the screen exactly – the stage about a third, the conversation all
  the free space, quick commands as one swipeable row, the input always above the bar. The page no longer scrolls.
- **Bottom bar on phones:** at most four areas with full names plus "More" (character, system, Knowlin). The emergency
  stop stays big and red next to it.
- **LM Studio under "Local model":** choose Ollama or LM Studio there – both run on this PC. "Other model" is for
  providers with a key. Existing LM Studio settings move over automatically.
- **Neutral about the language model:** "To Claude" is now "To Knowlin"; texts name the language model, whichever you use.
- **Fixed:** the decoration cup on the table stood inside Reachy Mini's base.
