# Knowlin 0.38.50 – “Kopf” instead of “Geist”, Ari holds the cube properly

*Deutsch unten.*

- **Changed:** the German texts on the website and in the docs now speak of Knowlin's *Kopf* (head) instead of *Geist*,
  which sounded like a ghost. English keeps “mind”.
- **Changed:** docs and website show Ari (SO-101) at its workbench and a section on values, drive, thought trail and
  hindsight.
- **Fixed:** below Ari's status it now says “holding the red cube” (German: “hält den roten Würfel”); the language
  model no longer reads that Ari holds it “in its beak” – at the workbench it is the gripper.
