# Knowlin 0.38.30 – Policies straight from Hugging Face

*Deutsch unten.*

- **Load policies from Hugging Face:** under Learn → Training → Policies from Isaac Lab, enter a Hugging Face address
  (`owner/repo`, `owner/repo/path.onnx` or a link). Knowlin downloads the ONNX file (only from huggingface.co, up to
  60 MB) and runs the same checks and test bench as for a file from your PC. Several policies in one repo? You pick one.
- **Suggestions:** Knowlin lists public Microduck repos with ONNX files on Hugging Face, most downloaded first – one
  click picks one.
- Polish on the Isaac Lab card: spacing to the next card, no empty gap under the button.

## Deutsch

Policies direkt von Hugging Face laden: Adresse eingeben, Knowlin lädt die ONNX-Datei (nur huggingface.co, bis 60 MB)
und prüft sie wie eine Datei vom PC. Dazu Feinschliff an der Karte „Policies aus Isaac Lab“.
