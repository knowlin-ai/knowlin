# Knowlin 0.38.31 – Windows installer and pip

*Deutsch unten.*

- **Knowlin-Setup.exe:** download it below under “Assets”, double-click, done – Python is included, no administrator
  rights needed. Start menu and desktop entries, clean uninstall via Windows Settings → Apps. Memory and settings stay
  when you update or uninstall. The installer isn't signed yet: if Windows says “Windows protected your PC”, click
  **More info → Run anyway**.
- **pip:** `pipx install knowlin`, then `knowlin --app` (Windows, macOS, Linux). On Windows, `knowlin --verknuepfung`
  adds the start menu and desktop entries.

## Deutsch

- **Knowlin-Setup.exe:** unten unter „Assets“ herunterladen und doppelklicken – Python ist dabei, keine
  Administratorrechte nötig. Warnt Windows vor einem unbekannten Herausgeber: „Weitere Informationen“ → „Trotzdem
  ausführen“ (der Installer ist noch nicht signiert).
