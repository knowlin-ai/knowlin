# Knowlin 0.38.42 – values that hold, dance poses that stand

*Deutsch unten.*

- **Values for every model:** Knowlin now has a fixed set of values – be honest, safety before curiosity, respect
  privacy, don't manipulate, decline with a reason – and every language model gets the same ones. Under Character →
  Personality the new card "Values and limits" also lists what Knowlin never does: limits that live in the code, each
  backed by a test.
- **Dance poses that stand:** before a dance, every saved pose is checked in an invisible physics world. Poses that
  would tip over are toned down until they stand – or only hinted at.
- **For contributors:** Knowlin is developed only in this public repo now; `tools/waechter.py` guards every push.

## Deutsch

- **Werte für jedes Modell:** Knowlin hat feste Werte – ehrlich sein, Sicherheit vor Neugier, Privatsphäre achten, nicht
  manipulieren, begründet ablehnen –, und jedes Sprachmodell bekommt dieselben. Unter Charakter → Persönlichkeit zeigt
  die neue Karte „Werte und Grenzen“ auch, was Knowlin nie tut: Grenzen, die im Code stecken, jede mit einem Test belegt.
- **Tanzposen, die stehen:** Vor dem Tanz prüft Knowlin jede gespeicherte Haltung in einer unsichtbaren Physik-Welt.
  Was umkippen würde, wird abgeschwächt, bis es steht – oder nur angedeutet.
- **Für Mitwirkende:** Knowlin entsteht nur noch in diesem öffentlichen Repo; `tools/waechter.py` prüft jeden Push.

Unten unter „Assets“: `Knowlin-Setup-0.38.42.exe`.
