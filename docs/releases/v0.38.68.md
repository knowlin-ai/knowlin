# Knowlin 0.38.68 – Map: points right on the wall stay inside

*Deutsch unten.*

- **Fixed:** if a measured point lay exactly on the boundary of a wall cell (rounded to millimetres), the map could
  clear one cell outside the room. Now it only clears up to 1 cm before the point. Found because the GitHub check for
  0.38.67 failed once on it; regression test with 3,000 random rays at the wall.
- Everything else as in 0.38.67 (brain activity as a galaxy).
- **Not tested:** with a real depth sensor.

## Deutsch

- **Behoben:** Lag ein gemessener Punkt genau auf der Grenze einer Wandzelle (auf Millimeter gerundet), konnte die
  Karte eine Zelle außerhalb des Zimmers freiräumen. Jetzt wird nur bis 1 cm vor dem Punkt freigeräumt. Aufgefallen,
  weil die Prüfung bei GitHub für 0.38.67 einmal daran scheiterte; Regressionstest mit 3000 Zufallsstrahlen auf die Wand.
- Sonst wie 0.38.67 (Hirnaktivität als Galaxie).
- **Nicht geprüft:** am echten Tiefensensor.

Unten unter „Assets“: `Knowlin-Setup-0.38.68.exe`.
