# Knowlin 0.38.34 – the in-app update that actually finishes

*Deutsch unten.*

- **Fixed:** “Update now” did not finish on the first real update. The window gave up after 90 seconds while the
  silent installer was still working. Now the window waits up to 5 minutes, the installer closes any running Knowlin
  from its folder before copying, and the update writes a log (`%LOCALAPPDATA%\duckpilot\updates\`). Settings → About
  shows how the last update went.
- **New:** the installer looks like the app – the Knowlin mark on a dark background.
- Before every installer, GitHub now installs the previous version, runs it, triggers the update through the app's own
  code and checks that the new version is installed and running again.

- **Also:** "Stop" under Dance no longer triggers the emergency stop · lock after the emergency stop selectable from
  15 seconds to 10 minutes (default 2 minutes) · tricks with previews and community packs on a fresh PC · switch body
  from the phone · clearer messages behind a proxy and when Hugging Face is unreachable · LM Studio and local models.

**Updating from 0.38.33:** "Update now" in 0.38.33 still uses the old code and does not finish (confirmed in the test
run on GitHub). Please download `Knowlin-Setup-0.38.34.exe` below once and install it over the old version – your data
stays. From 0.38.34 on, updates from the app work.

## Deutsch

- **Behoben:** „Jetzt aktualisieren“ lief beim ersten echten Update nicht durch. Das Fenster gab nach 90 Sekunden
  auf, während der stille Installer noch arbeitete. Jetzt wartet das Fenster bis zu 5 Minuten, der Installer beendet vor
  dem Kopieren selbst ein noch laufendes Knowlin, und das Update schreibt ein Protokoll
  (`%LOCALAPPDATA%\duckpilot\updates\`). Unter Einstellungen → Über steht, wie das letzte Update ausging.
- **Neu:** Der Installer sieht aus wie die App – das Knowlin-Zeichen auf dunklem Grund.
- Vor jedem Installer installiert GitHub jetzt die vorige Fassung, startet sie, löst das Update über den Code der App
  aus und prüft, dass danach die neue Version installiert ist und wieder läuft.

- **Außerdem:** „Stopp“ unter Tanzen löst keinen Not-Aus mehr aus · Sperre nach dem Not-Aus wählbar von 15 Sekunden bis
  10 Minuten (Standard 2 Minuten) · Tricks mit Vorschau und Community-Pakete auch auf einem neuen PC · Körper vom Handy
  wechseln · verständliche Meldungen hinter einem Proxy und ohne Hugging Face · LM Studio und lokale Modelle.

**Update von 0.38.33:** „Jetzt aktualisieren“ in 0.38.33 nutzt noch den alten Code und läuft nicht durch (im Testlauf bei
GitHub bestätigt). Bitte einmal `Knowlin-Setup-0.38.34.exe` unten laden und über die alte Fassung installieren – deine
Daten bleiben. Ab 0.38.34 klappen Updates aus der App.

Unten unter „Assets“: `Knowlin-Setup-0.38.34.exe`.
