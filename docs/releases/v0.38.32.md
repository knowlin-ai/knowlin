# Knowlin 0.38.32 – Updates from inside the app

*Deutsch unten.*

- **Update notice:** once a day Knowlin asks GitHub whether there is a new version and shows “Knowlin 0.38.xx is
  available” with “What's new”. You can turn this off under Settings → About, and check by hand there.
- **Update now:** with the Windows installer, Knowlin downloads the new installer from the release, verifies its SHA-256
  checksum against GitHub, closes, installs quietly and starts again. Installed with pipx/pip, it upgrades the package
  and restarts. Never while the real robot is connected.

## Deutsch

Knowlin meldet neue Versionen (einmal am Tag, abschaltbar) und aktualisiert sich auf Klick selbst – mit Prüfsumme, nie
während der echte Roboter verbunden ist. Unten unter „Assets“: `Knowlin-Setup-0.38.32.exe`.
