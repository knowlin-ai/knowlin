# Knowlin 0.38.33 – fixes from the first evening with the installer

*Deutsch unten.*

- **New:** Tricks now have a live preview next to the tiles, like dancing. The room map also learns while you drive by
  hand, not only in “Explore room”.
- **Fixed in the Windows installer:** Pollen's emotions were missing; add-ons that build from source (Qwen3-TTS or
  training on AMD graphics) failed with “No module named 'setuptools'”; Hugging Face suggestions said “not reachable”.
- **Fixed:** Settings → AI model → “Other model” listed no providers (OpenAI, Gemini, Mistral, OpenRouter, LM Studio,
  custom address). “Own model” is now called **“Local model”** (Ollama), with “Check again”.
- **Fixed in 3D:** free map cells behind the walls, flickering corners, jagged edges (FXAA), the duck hidden behind the
  plant in the colour previews.
- **Fixed:** the link to Pollen's Reachy Mini app catalog (404).
- First release you can reach with the in-app update from 0.38.32.

## Deutsch

- **Neu:** Tricks mit Live-Vorschau neben den Kacheln, wie beim Tanzen. Die Raumkarte lernt auch beim Fahren von Hand
  mit, nicht nur bei „Raum erkunden“.
- **Behoben im Windows-Installer:** Pollens Emotionen fehlten; Nachinstallationen, die aus dem Quellcode bauen
  (Qwen3-TTS oder Lernen mit AMD-Grafikkarte), scheiterten mit „No module named 'setuptools'“; die
  Hugging-Face-Vorschläge meldeten „nicht erreichbar“.
- **Behoben:** Einstellungen → KI-Modell → „Anderes Modell“ bot keine Anbieter an (OpenAI, Gemini, Mistral,
  OpenRouter, LM Studio, eigene Adresse). „Eigenes Modell“ heißt jetzt **„Lokales Modell“** (Ollama), mit „Erneut
  prüfen“.
- **Behoben in 3D:** freie Kartenzellen hinter den Wänden, flimmernde Ecken, Treppenkanten (FXAA), die Ente hinter dem
  Blumentopf in den Farbbildern.
- **Behoben:** der Link zu Pollens App-Katalog für Reachy Mini (404).
- Das erste Release, das du aus 0.38.32 heraus mit „Jetzt aktualisieren“ bekommst.

Unten unter „Assets“: `Knowlin-Setup-0.38.33.exe`.
