# Knowlin 0.38.63 – The emergency stop waits for nothing

*Deutsch unten.*

- **Safety: the emergency stop never waits behind a slow command.** The app sends everything over one connection, and
  the server used to handle messages strictly one after another – an emergency stop behind a command that waits (camera,
  arm, standing up on the real robot) would have waited too. Now it runs immediately, alongside whatever is working;
  commands that were ordered before it and had not started yet are dropped. This applies to the button, Esc, a game
  controller and the phone alike.
- **Not tested:** on the real robot (same path as in the simulator, but not measured on hardware).

## Deutsch

- **Sicherheit: Der Not-Aus wartet nie hinter einem langsamen Befehl.** Die Oberfläche schickt alles über eine
  Verbindung, und der Server arbeitete die Nachrichten bisher strikt nacheinander ab – ein Not-Aus hinter einem Befehl,
  der wartet (Kamera, Arm, Aufstehen am echten Roboter), hätte mitgewartet. Jetzt wirkt er sofort, neben allem, was
  gerade arbeitet; Befehle, die davor bestellt und noch nicht dran waren, verfallen. Das gilt für den Knopf, Esc, den
  Controller und das Handy gleich.
- **Nicht geprüft:** am echten Roboter (gleicher Weg wie im Simulator, aber nicht an Hardware gemessen).

Unten unter „Assets“: `Knowlin-Setup-0.38.63.exe`.
