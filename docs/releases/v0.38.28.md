# Knowlin 0.38.28 – Phone and tablet without hurdles

*Deutsch unten.*

- **On phone or tablet:** the start page has its own card – one click turns on remote access and shows a QR code plus a
  short code to type in (valid 5 minutes, one device, used up after 5 wrong tries).
- **knowlin.local:** while remote access is on, Knowlin announces its name on the home network (mDNS/Bonjour), so iPhone,
  iPad, Mac and Windows can open `knowlin.local:8766` without knowing the PC's address. Pairing is still required.

## Deutsch

Karte „Auf Handy oder Tablet“ auf der Startseite (einschalten, QR-Code, kurzer Code zum Eintippen) und `knowlin.local`
im Heimnetz, solange die Fernbedienung an ist.
