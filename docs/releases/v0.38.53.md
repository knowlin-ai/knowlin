# Knowlin 0.38.53 – Ari grabs with a click

*Deutsch unten.*

- **Fixed:** cubes and boxes on Ari's (SO-101) workbench can now be clicked. Click a cube for “Grab”; while Ari holds
  it, “Put it back in its place” or “Into the left/right box”; click a box for “Put it in here”. Before, the click hit
  the workbench and the menu offered to put Reachy on the floor.
- **Fixed:** the automatic checks on GitHub pass again (three dance-pose tests needed MuJoCo, which is not installed
  there). The release check now reports their result too.

## Deutsch

- **Behoben:** Würfel und Kisten auf Aris (SO-101) Werkbank lassen sich anklicken. Klick auf einen Würfel: „Greifen“;
  hält Ari ihn, „An seinen Platz legen“ oder „In die linke/rechte Kiste“; Klick auf eine Kiste: „Hier hineinlegen“.
  Bisher traf der Klick die Werkbank, und das Menü bot an, Reachy auf den Boden zu stellen.
- **Behoben:** Die automatische Prüfung bei GitHub ist wieder grün (drei Tests zu Tanzposen brauchten MuJoCo, das
  dort fehlt). Die Release-Nachprüfung meldet ihr Ergebnis jetzt mit.

Unten unter „Assets“: `Knowlin-Setup-0.38.53.exe`.
