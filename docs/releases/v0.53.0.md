# Knowlin 0.53.0 – Hiwonder's WonderDuck as the seventh body

*Deutsch unten.*

- **WonderDuck in the simulator** – meet **Wondi**: walks, turns, sits, moves its head, grabs with its beak, dances and
  plays sequences. Start-page tile, desktop shortcut, its own voice and personality.
- **Hiwonder's 3D model** (CC BY-NC-SA 4.0, © Hiwonder) is downloaded from Hiwonder's GitHub the first time you wake
  Wondi (fixed version with checksum, about 70 MB) and baked on your PC into a model of about 4 MB. Never in offline mode.
- **Real WonderDuck via robotd:** Hiwonder's software builds on Pollen's Microduck (protocol 62, same joints), so Knowlin
  talks to it the same way as to the Microduck. The connection test says what its software is still missing.
- **knowlin.de:** a page for the WonderDuck in English and German (`knowlin.de/en/wonderduck/`).
- **Not tested:** anything on a real WonderDuck – checked against the test robot and Hiwonder's source code only.

## Deutsch

- **WonderDuck im Simulator** – das ist **Wondi**: läuft, dreht sich, sitzt, bewegt den Kopf, greift mit dem Schnabel,
  tanzt und spielt Abläufe. Kachel auf der Startseite, Verknüpfung, eigene Stimme und Persönlichkeit.
- **Hiwonders 3D-Modell** (CC BY-NC-SA 4.0, © Hiwonder) lädt Knowlin beim ersten Wecken von Hiwonders GitHub (fester Stand
  mit Prüfsumme, etwa 70 MB) und baut daraus auf deinem PC ein Modell von gut 4 MB. Nie im Offline-Modus.
- **Echte WonderDuck über robotd:** Hiwonders Software baut auf Pollens Microduck auf (Protokoll 62, dieselben Gelenke) –
  Knowlin spricht sie wie die Microduck an. Der Verbindungstest sagt, was ihrer Software noch fehlt.
- **knowlin.de:** eigene Seite für die WonderDuck, deutsch und englisch (`knowlin.de/wonderduck/`).
- **Nicht geprüft:** alles an einer echten WonderDuck – nur gegen den Test-Roboter und Hiwonders Quellcode abgeglichen.
