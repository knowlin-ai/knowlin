# Knowlin 0.38.16 – Ready for the real robot

*Deutsch unten.*

- **Connection check before the first start on a real robot:** in “First steps” and in the settings, “Check
  connection” tests the address of the Microduck (robotd) or Pollen's Reachy Mini daemon – reachable, version, battery.
  It only reads; nothing moves. Every finding is shown with a symbol and text.
- **Honest accessibility:** the goal is WCAG 2.2 AA, checked automatically with axe-core; testing with real screen
  readers is still to do – feedback welcome.
- **`start.sh` works like `start.bat`:** checks for Python ≥ 3.11, reinstalls packages when `requirements.txt`
  changes, explains a missing `python3-venv`, and no longer creates a `.env` – the key goes into the app (OS vault).
- English screenshots in the English README; a `knowlin` command next to `duckpilot`; clearer `--help`.
- Fixed: parts of the English interface stayed German (current activity, answer source, Reachy hints, names in the
  experience network).
