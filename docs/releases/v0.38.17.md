# Knowlin 0.38.17 – Lean and modular

*Deutsch unten.*

- **Frontend in modules:** `app.js` only wires things together now (98 → 67 KB); settings, header bar, tricks page,
  memory, events, sensor tile and touch pad are modules of their own, shared helpers live in `ui.js`. Dead code removed;
  new guard rails: JS modules ≤ 64 KB, `app.js` ≤ 72 KB, no unused modules.
- **Runtime and motion split up:** conversation as its own runtime part, choreography and gesture catalogues as
  `motion/choreografie.py` – existing imports keep working.
- **Security on GitHub:** Dependabot, CodeQL (once the repo is public) and a dependency audit (pip-audit) on every push.
  No known vulnerabilities today.

- **PyPI ready:** the package will be `knowlin` (`pip install knowlin`), published from GitHub via Trusted Publishing –
  no API keys involved.

Nothing changes for users – same behaviour, easier to contribute.
