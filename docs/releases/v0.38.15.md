# Knowlin 0.38.15 – Polish before the launch

*Deutsch unten.*

- **Simple Open Duck:** the simple 3D view now fits Odi too – grey, taller, with antennas – instead of the simple
  Microduck.
- **No lost messages:** if the connection to the server dropped exactly while sending, the message was lost silently.
  The browser now sends it again after reconnecting; the server accepts it only once.
- The console and `--version` say “Knowlin”; the Knowlin mark is now the public mark; the README shows a short animation
  (a still image with “reduce motion”).

## Deutsch

Die einfache 3D-Darstellung passt jetzt auch zur Open Duck (grau, höher, mit Antennen). Nachrichten gehen bei einem
Verbindungsabbruch nicht mehr verloren. Konsole und `--version` sagen „Knowlin“, das Knowlin-Zeichen ist das öffentliche
Zeichen, und die README zeigt eine kurze Animation der Startseite.
